## 先做哪几个

如果只做一批稳定版：**D3 + C3 + D4b + B3**。这四项分别对应「测试拦不住回归」「历史/拼装板可能丢」「发布产物不够正式」「连接测试不真实」，都属于 2.0 之后最值得补的短板。

如果做一轮体验升级：**A6 + A7 + A8 + C4**。如果做下一个大功能：**A3 多方案生成**，单独当一次版本主题。

## P0 · 发布后优先补强

### D3 · 测试与 CI 加固 — 价值 高 / 成本 中

- [ ] 现状：CI 只跑静态检查和服务器 smoke，没有跑 UI 回归；服务端关键函数没有单元测试；GitHub Actions 已提示 Node 20 弃用。
- [ ] 做什么：
  - 用 `node:test` 补 `normalizeBaseURL`、配置恢复、保存/重命名/回收站、SSE 解析、备份导入等纯服务端逻辑；
  - CI 安装 Chrome 跑完整 `npm test`；
  - Windows job 增加打包冒烟：启动 exe、请求 `/api/config`、检查版本和静态资源；
  - 把 Actions 和 Node 版本升到当前受支持版本。
- [ ] 验收：CI 能拦住前端回归；服务端单测覆盖关键路径；打包产物能启动并返回 200；不再出现 Node 20 弃用告警。

### C3 · 历史与拼装板落盘 — 价值 高 / 成本 中

- [ ] 现状：历史（上限 60）和拼装板仍只存在 localStorage；换浏览器、清缓存或换设备会丢。2.0 的备份只能手动导出。
- [ ] 做什么：
  - 迁移到数据目录的 JSON 文件，通过 `/api/history`、`/api/board` 读写；
  - 首次启动自动迁移旧 localStorage；
  - 历史上限、拼装板内容可配置；
  - 文件损坏时回退到空状态并提示，不阻塞启动。
- [ ] 验收：换浏览器/重启后数据还在；旧 localStorage 能迁移；损坏文件有兜底；桌面版和源码版行为一致。

### D2 · 键盘与无障碍 — 价值 中 / 成本 低

- [ ] 现状：保存库/历史条目是 `div` 点击，键盘无法操作；抽屉没有焦点陷阱；没有快捷键帮助。
- [ ] 做什么：
  - 列表项改成可聚焦控件，支持 Tab + Enter / Space；
  - 抽屉打开时焦点陷阱，关闭后焦点归还触发按钮；
  - 增加 `?` 快捷键帮助面板；
  - 流式状态、toast 和错误用 `aria-live` 播报。
- [ ] 验收：只用键盘能打开抽屉、载入、删除、关闭；Esc 行为一致；屏幕阅读器能读到流式进度。

### D4b · 发布工程剩余项 — 价值 高 / 成本 低

- [ ] 已完成：版本号显示、CHANGELOG、README 截图更新、发布说明模板、2.0 Release 自动发布。
- [ ] 还缺：
  - 为两种 exe 配置自定义 `.ico`（目前仍是默认 Node/Electron 图标）；
  - 发布产物生成 SHA256 校验文件；
  - 补一张拼装板/历史界面的 README 截图；
  - 检查 electron-builder 产物元数据（产品名、版本、版权）。
- [ ] 验收：exe 图标正确；Release 附带校验文件；README 截图覆盖 2.0 主要界面。

### B3 · 真实连接测试 — 价值 中 / 成本 低

- [ ] 现状：「测试连接」只请求 `/models`，部分兼容服务不实现这个接口，配置明明可用却测试失败。
- [ ] 做什么：发送一条最小 chat 请求，显示延迟、返回模型名和一句回声；`/models` 不可用时仍能通过测试。
- [ ] 验收：只支持 `/chat/completions` 的服务也能测试成功；Key/BaseURL 错误有明确提示；不产生历史或保存文件。

## P1 · 下一功能批次

### A6 · 版本时间线与复制格式 — 价值 中 / 成本 中

- [ ] 现状：微调栈只能逐步撤回，不能直接跳到某个旧版本，也没有差异提示。
- [ ] 做什么：把微调栈做成可点选时间线；任意版本恢复；显示与上一版差异；复制支持只正向 / 只负向 / JSON / Midjourney 参数。
- [ ] 验收：跳到旧版本内容一致；差异高亮准确；每种复制格式正确；历史同步更新。

### A7 · 模板 / 预设与画幅快捷 — 价值 中 / 成本 低中

- [ ] 做什么：常用题材模板（人像、场景、机甲、国风等）一键填句；负面词预设；自定义目标模型；提示词模式补画幅/镜头/构图快捷；可保存自定义预设。
- [ ] 验收：模板能带上风格/画幅等设置；自定义预设刷新后还在；画幅要求进入提示词或参数建议。

### A8 · 草稿自动保存 — 价值 中 / 成本 低

- [ ] 做什么：三个模式的输入、附加要求、当前结果自动保存；刷新/崩溃后恢复；提供「清空草稿」。
- [ ] 验收：刷新页面输入不丢；按模式隔离；清空后不再恢复；不会把 API Key 写进草稿。

### C4 · 回收站管理界面 — 价值 中 / 成本 低

- [ ] 现状：删除后只有提示条上的撤销，回收站没有浏览/恢复入口。
- [ ] 做什么：抽屉查看回收站文件；单条/批量恢复；彻底删除；显示剩余保留天数。
- [ ] 验收：删除后能在回收站看到；恢复后回到保存库；彻底删除不可恢复；7 天自动清理仍生效。

### B4 · 多服务商档案与 Key 安全 — 价值 中 / 成本 中

- [ ] 做什么：保存多套 BaseURL/Key/模型配置，一键切换；Key 可选系统凭据加密（Windows DPAPI / Electron safeStorage）；设置页增加配置校验；支持导出脱敏诊断信息。
- [ ] 验收：两套配置切换后请求走对应地址；Key 不回显；诊断信息不含明文 Key；源码版保持明文方案并明确提示。

### D5 · 桌面版细节 — 价值 中 / 成本 低

- [ ] 现状：Electron 主进程没有单实例锁，重复启动会开多个服务和窗口。
- [ ] 做什么：`requestSingleInstanceLock`，第二次启动聚焦已有窗口；可选托盘/开机启动；记忆窗口大小和位置。
- [ ] 验收：双击两次只保留一个窗口；关闭行为明确；窗口位置刷新后恢复。

### A3 · 多方案生成与对比 — 价值 高 / 成本 高

- [ ] 做什么：一句话一次生成 3 条候选；并排展示标题、正向、负向和解读；选中一条继续微调/保存；支持「再来一批」。
- [ ] 验收：3 条结果互不污染；选中后微调和保存正常；取消只停当前批次；失败时保留已成功候选。
- [ ] 备注：适合单独作为一个大版本主题，不和别的功能混做。

- [ ] 验收：英文模式下主要流程无残留中文；错误提示、空状态、toast 都有英文。

## 不建议现在做

- **云同步 / 账号系统**：和「纯本地、不上传数据」的定位冲突。
- **内置生图 / 模型托管**：成本和定位都变了，容易把工具做重。
- **多用户 / 权限**：本地单用户工具暂时不需要。
- **全量 TypeScript 重写**：收益低、风险高，先 `checkJs` 逐步补类型。
- **Electron 自动更新**：当前是 portable exe，自动更新成本高，先做「检查新版本」链接。
