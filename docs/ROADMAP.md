## P1 · 下一功能批次

### A6 · 版本时间线与复制格式 — 价值 中 / 成本 中

- [ ] 现状：微调栈只能逐步撤回，不能直接跳到某个旧版本，也没有差异提示。
- [ ] 做什么：把微调栈做成可点选时间线；任意版本恢复；显示与上一版差异；复制支持只正向 / 只负向 / JSON / Midjourney 参数。
- [ ] 验收：跳到旧版本内容一致；差异高亮准确；每种复制格式正确；历史同步更新。

### A7 · 模板 / 预设与画幅快捷 — 价值 中 / 成本 低中

- [ ] 做什么：常用题材模板（人像、场景、机甲、国风等）一键填句；负面词预设；自定义目标模型；提示词模式补画幅/镜头/构图快捷；可保存自定义预设。
- [ ] 验收：模板能带上风格/画幅等设置；自定义预设刷新后还在；画幅要求进入提示词或参数建议。

### A8 · 草稿自动保存 — 价值 中 / 成本 低

- [ ] 做什么：三个模式的输入、附加要求、当前结果自动保存；刷新/崩溃后恢复；提供「清空草稿」。
- [ ] 验收：刷新页面输入不丢；按模式隔离；清空后不再恢复；不会把 API Key 写进草稿。

### C4 · 回收站管理界面 — 价值 中 / 成本 低

- [ ] 现状：删除后只有提示条上的撤销，回收站没有浏览/恢复入口。
- [ ] 做什么：抽屉查看回收站文件；单条/批量恢复；彻底删除；显示剩余保留天数。
- [ ] 验收：删除后能在回收站看到；恢复后回到保存库；彻底删除不可恢复；7 天自动清理仍生效。

### B4 · 多服务商档案与 Key 安全 — 价值 中 / 成本 中

- [ ] 做什么：保存多套 BaseURL/Key/模型配置，一键切换；Key 可选系统凭据加密（Windows DPAPI / Electron safeStorage）；设置页增加配置校验；支持导出脱敏诊断信息。
- [ ] 验收：两套配置切换后请求走对应地址；Key 不回显；诊断信息不含明文 Key；源码版保持明文方案并明确提示。

### D5 · 桌面版细节 — 价值 中 / 成本 低

- [ ] 现状：Electron 主进程没有单实例锁，重复启动会开多个服务和窗口。
- [ ] 做什么：`requestSingleInstanceLock`，第二次启动聚焦已有窗口；可选托盘/开机启动；记忆窗口大小和位置。
- [ ] 验收：双击两次只保留一个窗口；关闭行为明确；窗口位置刷新后恢复。

### A3 · 多方案生成与对比 — 价值 高 / 成本 高

- [ ] 做什么：一句话一次生成 3 条候选；并排展示标题、正向、负向和解读；选中一条继续微调/保存；支持「再来一批」。
- [ ] 验收：3 条结果互不污染；选中后微调和保存正常；取消只停当前批次；失败时保留已成功候选。
- [ ] 备注：适合单独作为一个大版本主题，不和别的功能混做。

## 不建议现在做

- **云同步 / 账号系统**：和「纯本地、不上传数据」的定位冲突。
- **内置生图 / 模型托管**：成本和定位都变了，容易把工具做重。
- **多用户 / 权限**：本地单用户工具暂时不需要。
- **全量 TypeScript 重写**：收益低、风险高，先 `checkJs` 逐步补类型。
- **Electron 自动更新**：当前是 portable exe，自动更新成本高，先做「检查新版本」链接。
